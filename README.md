# Customer Behavior Data Analyst Portfolio Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from loading and cleaning raw data to analyzing it with SQL and presenting insights through an interactive Power BI dashboard.

The project covers:

* Loading and exploring a dataset using Python
* Performing Exploratory Data Analysis (EDA)
* Cleaning and preparing the data
* Writing SQL queries in PostgreSQL for analysis
* Building an interactive Power BI dashboard

---

## Dataset

The dataset contains structured data used for analysis and visualization.

**Key features:**

* Multiple variables for business analysis
* Missing values and inconsistencies handled during data cleaning
* Suitable for SQL analysis and dashboard reporting

## Project Steps

### 1. Data Loading

* Imported the dataset into Python using Pandas.
* Inspected data structure and basic information.

### 2. Exploratory Data Analysis (EDA)

* Generated summary statistics.
* Identified missing values and outliers.
* Explored distributions and relationships using visualizations.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected data types.
* Standardized and prepared the dataset for analysis.

### 4. SQL Analysis

* Imported the cleaned dataset into PostgreSQL.
* Wrote SQL queries to answer business questions.
* Used filtering, grouping, joins, sorting, and aggregate functions.

### 5. Power BI Dashboard

* Connected Power BI to the processed data.
* Built interactive visualizations and dashboards.
* Added filters and slicers for better user interaction.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook and run all cells.
4. Import the cleaned dataset into PostgreSQL.
5. Execute the SQL queries.
6. Open the Power BI (.pbix) file to explore the dashboard.
